Learn HTML

HTML (HyperText Markup Language) is the foundation of every website on the internet. It is used to create the structure of web pages, including headings, paragraphs, images, links, forms, and much more.

In this course, you will learn how to build web pages from scratch, understand how websites are structured, and create real projects using modern HTML.
